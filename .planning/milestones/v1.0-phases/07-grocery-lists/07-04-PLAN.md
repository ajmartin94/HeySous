  <files>src/bot/handlers/grocery.ts</files>
  <action>
Create src/bot/handlers/grocery.ts following the pattern of src/bot/handlers/plan.ts.

Two factory functions:

**1. createGroceryHandler(sqlite: BetterSqlite3.Database): Composer&lt;BotContext&gt;**

Handles the /grocery command (instant display, no Claude call):
- Import createGroceryRepository from "../../grocery/repository.js"
- Create repository instance inside the factory (same pattern as plan handler using raw sqlite)
- On /grocery command:
  - Get chatId from ctx.chat.id (as string)
  - Call groceryRepository.getActiveList(chatId)
  - If no active list: reply with "No grocery list yet! Just say something like \"make my grocery list\" and I'll generate one from your meal plan."
  - If active list exists:
    - Get items via groceryRepository.getListItems(list.id)
    - Format with formatGroceryList(items) from "../../grocery/formatter.js"
    - Build keyboard with buildGroceryKeyboard(items) from "../../grocery/buttons.js"
    - Send via ctx.reply(formattedList, { reply_markup: keyboard, parse_mode: "HTML" })
    - Store the sent message ID: groceryRepository.setMessageId(list.id, sentMessage.message_id)
    - This ensures the latest /grocery invocation becomes the editable message

**2. createGroceryCallbackHandler(sqlite: BetterSqlite3.Database): Composer&lt;BotContext&gt;**

Handles inline button taps for item check-off:
- Import parseGroceryCallback from "../../grocery/buttons.js"
- Create repository instance inside the factory
- Use handler.on("callback_query:data", ...) to match ALL callback queries (not just grocery ones)
  - Parse callback data with parseGroceryCallback(ctx.callbackQuery.data)
  - If null (not a grocery callback), call next() to pass to other handlers
  - If action is "t" (toggle):
    1. Immediately call `await ctx.answerCallbackQuery()` to clear the loading spinner
    2. Toggle item: groceryRepository.toggleItem(parsed.itemId)
    3. Get listId: groceryRepository.getListIdForItem(parsed.itemId)
    4. If no listId, return (item was deleted)
    5. Get all items: groceryRepository.getListItems(listId)
    6. Rebuild message: formatGroceryList(items)
    7. Rebuild keyboard: buildGroceryKeyboard(items)
    8. Try ctx.editMessageText(formattedMessage, { parse_mode: "HTML", reply_markup: keyboard })
    9. Catch GrammyError where description includes "message is not modified" -- silently ignore (expected with rapid taps)
    10. Re-throw any other error

Import GrammyError from "grammy" for error type checking.

IMPORTANT: The callback handler uses handler.on("callback_query:data", ...) NOT handler.callbackQuery(). This allows checking if it's a grocery callback and passing to next() if not. Use .js extensions on all local imports.

    // m2. Edit grocery list message if tools modified it

    if (deps.groceryRepository) {
      try {
        const activeList = deps.groceryRepository.getActiveList(chatId);
        if (activeList && activeList.messageId) {
          const groceryItems = deps.groceryRepository.getListItems(activeList.id);
          const formattedList = formatGroceryList(groceryItems);
