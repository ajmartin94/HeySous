<objective>
Fix phantom reminder bug: deleteAllPending skips 'sent' reminders during regeneration, allowing stale prep alerts to fire for replaced meals.

Purpose: UAT test 3 failed -- user got a prep alert for the OLD meal after changing tomorrow's dinner. The poller had already marked the old prep alert as 'sent' (before actual delivery), so deleteAllPending missed it. The fix is to delete ALL reminders for the household during regeneration, regardless of status.

Output: Updated repository method, updated generator call, test proving sent reminders are deleted.
</objective>
