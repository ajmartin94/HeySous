  <action>
Refactor Settings.tsx to use a side-tabbed layout. Keep all existing state, hooks, API calls, and logic unchanged -- only restructure the JSX and add tab state.

**Tab state:**
- Add `type SettingsTab = 'app' | 'schedule' | 'memory'`
- Add `const [activeTab, setActiveTab] = useState<SettingsTab>('app')`

**Layout structure (per user decision -- side tabs, NOT top tabs):**
```
+--------+---------------------------+
| App    |                           |
|        |   [active tab content]    |
| Sched  |                           |
|        |                           |
| Memory |                           |
+--------+---------------------------+
```

- Outer container: `display: flex`, full height of parent
- Left sidebar: ~80px wide, vertical stack of tab buttons, left-aligned text labels
- Right content area: `flex: 1`, padding, overflow-y auto for scrollable content

**Sidebar tab buttons:**
- Three buttons stacked vertically: "App", "Schedule", "Memory" (this exact order per user decision)
- Active tab: use accent color background (`var(--hs-accent)`) with white text, matching the existing `pillStyle(true)` pattern
- Inactive tabs: subtle background (`var(--tg-theme-secondary-bg-color)`), normal text color
- Each button: full sidebar width, padding 12px, text-align left, border-radius on right side (e.g., `borderRadius: '0 8px 8px 0'`)
- No transition/animation between tabs (keep it simple)

**Tab content panels (conditional render based on activeTab):**

App tab (`activeTab === 'app'`):
- Theme section label + pill row (existing themeOptions map)
- Text Size section label + pill row (existing fontSizeOptions map)
- Preview box (existing preview div)

Schedule tab (`activeTab === 'schedule'`):
- Show loading state if `settingsLoading || !settings`
- Timezone read-only input
- Meal time inputs (existing timeFields map)
- Morning summary toggle
- Prep alerts toggle
- Saved confirmation message

Memory tab (`activeTab === 'memory'`):
- Show loading state if `memoriesLoading`
- Empty state if no categories
- Category cards with memory items and delete buttons (existing JSX)

**Keep the "Settings" header** above the flex container (outside the tab layout).

**Important:** Do NOT extract into sub-component files. Keep as a single Settings.tsx file with tab state. All existing hooks (useEffect for fetch, useCallback for delete/save, backButton, debounce) remain untouched. Only the return JSX and tab state change.

Remove the `sectionLabelStyle` usage within tab content since the tab itself provides the section context. Individual sub-section labels within a tab (like "Theme", "Text Size", "Timezone") should use a lighter label style (just the small font + hint color, no uppercase/letterSpacing needed since tabs provide hierarchy).
