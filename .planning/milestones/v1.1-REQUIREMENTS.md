# Requirements Archive: HeySous v1.1 Mini Apps

**Archived:** 2026-02-10
**Status:** All requirements validated via UAT (20/20 tests passing)

## Infrastructure

- [x] **INFRA-01**: User can open Mini Apps from the bot via inline keyboard buttons that launch Telegram WebView
- [x] **INFRA-02**: Server validates every Mini App API request using initData HMAC-SHA256 with 1-hour expiration, rejecting unauthorized requests with 401
- [x] **INFRA-03**: Mini App frontend is a React+Vite SPA served as static files from the existing Express server at /app/*
- [x] **INFRA-04**: REST API routes at /api/* reuse existing repository functions (groceryRepository, planRepository, knowledgeRepository) via the same DI pattern
- [x] **INFRA-05**: Mini App SDK initializes correctly on iOS: disableVerticalSwipes, expand to full viewport, safe area insets handled via contentSafeAreaInset
- [x] **INFRA-06**: Mini App theme matches Telegram's light/dark mode via CSS variables (--tg-theme-*) and @telegram-apps/telegram-ui components
- [x] **INFRA-07**: BotFather menu button is configured to open the primary Mini App URL

## Grocery List Mini App

- [x] **GROC-01**: User can view their active grocery list with items grouped by store (Kroger/Costco) via tab navigation
- [x] **GROC-02**: User can see items grouped by section (Produce, Dairy, etc.) within each store tab
- [x] **GROC-03**: User can tap an item to check/uncheck it with haptic feedback and optimistic UI update
- [x] **GROC-04**: User can see checked items in a collapsed "Done" section at the bottom of each store tab
- [x] **GROC-05**: User can see shopping progress as a count indicator (e.g., "12/28 items") per store and overall
- [x] **GROC-06**: User can see item quantities displayed alongside names (e.g., "2 lbs chicken thighs")
- [x] **GROC-07**: User can tap Telegram's MainButton ("Done Shopping") to mark the shopping trip complete
- [x] **GROC-08**: User can tap Telegram's BackButton to return to the chat from the grocery list
- [x] **GROC-09**: User can swipe an item to uncheck it from the Done section
- [x] **GROC-10**: User can add a forgotten item to the grocery list without returning to chat via a quick-add form

## Recipe Browser Mini App

- [x] **RECIPE-01**: User can browse all stored recipes as a scrollable card list showing title, summary snippet, and tags
- [x] **RECIPE-02**: User can search recipes by typing in a search bar with debounced FTS5 full-text search
- [x] **RECIPE-03**: User can tap a recipe card to view the full recipe detail (ingredients, instructions, notes)
- [x] **RECIPE-04**: User can see tag pills on each recipe card for quick visual scanning
- [x] **RECIPE-05**: User can navigate back from recipe detail to the card list using Telegram's BackButton, with scroll position preserved
- [x] **RECIPE-06**: User can tap a tag to filter the recipe list to only recipes with that tag
- [x] **RECIPE-07**: User can see the "last cooked" date on each recipe card showing when the dish was last made

## Meal Plan Mini App

- [x] **PLAN-01**: User can view the current week's meal plan as a 7-day grid (Monday-Sunday) with recipe names in each cell
- [x] **PLAN-02**: User can see meal type rows that adapt to content (dinner-only shows single row, multi-meal shows breakfast/lunch/dinner rows)
- [x] **PLAN-03**: User can see today's date highlighted in the grid for quick orientation
- [x] **PLAN-04**: User can toggle between current week and next week plans
- [x] **PLAN-05**: User can tap a meal name to see the linked recipe detail (reusing RecipeDetail component)
- [x] **PLAN-06**: User can see visual meal type indicators (color-coded or icon-based) for breakfast/lunch/dinner
