<task type="auto">
  <name>Task 1: Create /preferences command handler</name>
  <files>src/bot/handlers/preferences.ts</files>
  <action>
Create `src/bot/handlers/preferences.ts` following the EXACT pattern of `costs.ts` and `debug.ts`:

1. Export a `createPreferencesHandler(sqlite: BetterSqlite3.Database): Composer<BotContext>` factory function.

2. Register a `handler.command("preferences", async (ctx) => { ... })` that:
   a. Gets chatId from `String(ctx.chat.id)`
   b. Calls `getPreferenceSummaries(sqlite, chatId)` to load all preferences
   c. If no preferences, replies with a helpful empty-state message: "No preferences saved yet! Just tell me things like \"we eat dinner at 6pm\" or \"no shellfish\" and I'll remember."
   d. If preferences exist, groups them and formats as HTML, then sends via `sendFormattedMessage(ctx, message)`.

3. No admin restriction -- any user can view their own preferences (same as /debug, unlike /costs).

4. Grouping logic -- create a `groupPreferences(prefs: PreferenceSummary[])` function:
   - `household`: any preference with `subject:household` tag (regardless of other domain tags)
   - `dietary`: preferences with `pref:dietary` tag (not already in household)
   - `schedule`: preferences with `pref:schedule` tag (not already in household)
   - `cooking`: preferences with `pref:cooking`, `pref:budget`, `pref:serving`, or `pref:grocery` tag (not already in household)
   - `other`: everything else not yet categorized

   A preference only goes into ONE group. Priority: household > dietary > schedule > cooking > other.

5. Format each preference line with markers:
   - `[ALLERGY]` if tags include `severity:allergy`
   - `[RESTRICTION]` if tags include `severity:restriction`
   - `[inferred]` if tags include `inferred`
   - Format: `- {title}{markers}`

6. Overall HTML format:
   ```
   <b>Your Preferences</b>

   <b>Dietary</b>
   - No shellfish [ALLERGY]
   - Prefers Mediterranean cuisine

   <b>Schedule</b>
   - Dinner at 6pm weekdays
   - Quick meals on Tuesdays [inferred]

   <b>Household</b>
   - Kid's peanut allergy [ALLERGY]

   <b>Cooking</b>
   - Has an Instant Pot

   <i>Say "forget [preference]" to remove, or tell me if anything changed.</i>
   ```
   Only include sections that have items. The footer hint is always present.

7. Use `.js` extensions on all local imports.
8. Import types: `type BetterSqlite3 from "better-sqlite3"`, `type { BotContext } from "../context.js"`.
9. Import: `{ Composer } from "grammy"`, `{ getPreferenceSummaries, type PreferenceSummary } from "../../knowledge/preferences.js"`, `{ sendFormattedMessage } from "../../telegram/sender.js"`.
