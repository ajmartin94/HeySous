<task type="auto">
  <name>Task 2: Create Claude client, system prompt, and AI types</name>
  <files>
    src/ai/types.ts
    src/ai/system-prompt.ts
    src/ai/claude-client.ts
  </files>
  <action>
    1. Create `src/ai/types.ts` with TypeScript types:
       ```typescript
       export interface ClaudeResponse {
         text: string;
         usage: TokenUsage;
         model: string;
         stopReason: string;
       }

       export interface TokenUsage {
         inputTokens: number;
         outputTokens: number;
         cacheCreationInputTokens: number;
         cacheReadInputTokens: number;
       }

       // Haiku 4.5 pricing per MTok
       export const MODEL_PRICING: Record<string, ModelPricing> = {
         "claude-haiku-4-5-20251001": {
           inputPerMTok: 1.00,
           outputPerMTok: 5.00,
           cacheWritePerMTok: 1.25,
           cacheReadPerMTok: 0.10,
         },
       };

       export interface ModelPricing {
         inputPerMTok: number;
         outputPerMTok: number;
         cacheWritePerMTok: number;
         cacheReadPerMTok: number;
       }
       ```

    2. Create `src/ai/system-prompt.ts`:
       Build the Sous persona system prompt per locked user decisions:
       - Warm and casual tone, like a friend who loves cooking
       - Named persona: "Sous" -- the user's kitchen sidekick
       - Strict food-only boundaries with polite, in-character declines
       - Actively helpful and proactive (suggests ideas, follows up, nudges)
       - Export `buildSystemPrompt(): string`
       - Keep responses concise (1-3 short paragraphs unless detail requested)
       - Instruct HTML formatting for Telegram: `<b>bold</b>` for emphasis, `<i>italic</i>` for ingredient names
       - Instruct to NEVER use markdown syntax (no **, no ##, no ```)
       - Note: This is a function (not constant) to allow future phases to inject context (knowledge, preferences)

    3. Create `src/ai/claude-client.ts`:
       - Export a factory: `createClaudeClient(apiKey: string, model: string)` that returns an object with `sendMessage(userMessages: string[]): Promise<ClaudeResponse>`
       - Factory pattern matches existing codebase convention (createDatabase, createBot)
       - Instantiate `new Anthropic({ apiKey, maxRetries: 0, timeout: 60_000 })`
         - maxRetries: 0 per research -- we handle retries ourselves for user-facing messaging
         - timeout: 60_000 (60 seconds)
       - `sendMessage` implementation:
         a. Call `buildSystemPrompt()` to get the system prompt
         b. Join userMessages with `"\n\n"` as the user message content
         c. Call `client.messages.create()` with:
            - model from constructor
            - max_tokens: 2048
            - system: array with one text block containing the system prompt, with `cache_control: { type: "ephemeral" }` on it (costs nothing if below 4096 token minimum, positions for Phase 3+)
            - messages: single user message with combined text
         d. Extract text from response content blocks (filter for type === "text", map to .text, join with "\n")
         e. Return ClaudeResponse with text, usage (mapping response.usage fields including cache_creation_input_tokens and cache_read_input_tokens, defaulting to 0 if undefined), model from response, stopReason from response
       - Export `calculateCost(model: string, usage: TokenUsage): number` that computes USD cost using MODEL_PRICING lookup. Return 0 for unknown models.
       - Use .js extensions on all local imports (ESM convention from Phase 1)
  </action>
  <verify>
    - `npx tsc --noEmit` passes with zero errors
    - `node -e "import('./dist/ai/claude-client.js')"` after build -- module loads without errors (does NOT need API key to import)

  <done>
