Add a `refreshUserCache` function alongside `addToCache` in the returned interface:
```typescript
interface AccessGateResult {
  middleware: MiddlewareFn<BotContext>;
  addToCache: (user: User) => void;
  refreshUserCache: (user: User) => void;  // NEW
```
