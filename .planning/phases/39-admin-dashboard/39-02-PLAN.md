**mini-app/src/hooks/useAdminData.ts** — Custom hook for fetching admin dashboard data.

Create `useAdminData()` hook that manages state for all four admin API endpoints. Uses `apiFetch` from `../api`.

Interface types to define (matching API response shapes from Plan 01):
- `ActivityEvent`: `{ id, eventType, userId, userName, timestamp, details }`
- `StatsData`: `{ summary: { messagesCount, activeUsers, apiCalls, totalUsers, totalRecipes }, daily: Array<{ day, messageCount }> }`
- `CostsData`: `{ totalCost, dailyBudgetTokens, byModel: Array<{ model, cost, tokens }>, byUser: Array<{ userId, userName, cost }>, daily: Array<{ day, cost }> }`
- `FeedbackEntry`: `{ id, userId, userName, text, source, timestamp }`

Hook state:
- `activity: { events, hasMore, loading, error }` — fetched from /api/admin/activity
- `stats: { data, loading, error }` — fetched from /api/admin/stats
- `costs: { data, loading, error }` — fetched from /api/admin/costs
- `feedback: { entries, total, recentCount, hasMore, loading, error }` — fetched from /api/admin/feedback

Hook parameters/actions:
- `range`: 'today' | '7d' | '30d' state (default: 'today') — shared across stats and costs
- `setRange(range)`: updates range and refetches stats + costs
- `activityFilter`: { type: string, userId: string } state
- `setActivityFilter(filter)`: updates filter and refetches activity
- `loadMoreActivity()`: increments offset, fetches next page, appends to events
- `loadMoreFeedback()`: same pattern for feedback
- `refresh()`: refetches all four endpoints from scratch

On mount, fetch all four endpoints with default params. Use `let cancelled = false` pattern for cleanup (consistent with useUserRole, useRecipes).

Export the hook and all type interfaces.

**mini-app/src/components/admin/BarChart.tsx** — Lightweight SVG bar chart.

Create a simple, reusable `BarChart` component for rendering trend data.

Props:
- `data: Array<{ label: string; value: number }>` — the data points (days)
- `height?: number` — chart height in px (default 120)
- `color?: string` — bar color (default: var(--hs-accent) via inline style)
- `budgetLine?: number` — optional horizontal reference line value (for cost chart budget line)
- `formatValue?: (v: number) => string` — tooltip/label formatter

Implementation:
- Pure SVG, no external dependencies
- Chart width fills container (use viewBox with preserveAspectRatio)
- Bars are evenly spaced rectangles with proportional heights based on max value
- If `budgetLine` provided, draw a dashed horizontal line at the corresponding Y position with a small label
- X-axis labels show the `label` field (day abbreviations) — skip every other label if >14 data points to avoid crowding
- Y-axis: show max value label at top
- Bars use rounded top corners (rx=2)
- Colors: bars use `color` prop, budget line uses a muted red (var(--tg-theme-destructive-text-color, #e53935))
- No animation, no hover effects — keep it simple for mobile Telegram WebView
- Responsive: chart SVG has `width="100%"` and a fixed height
