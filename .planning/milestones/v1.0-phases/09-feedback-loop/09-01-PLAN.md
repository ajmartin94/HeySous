1. **Create src/feedback/generator.ts** -- Generate feedback_checkin reminders from meal plans. Follow the pattern of reminders/generator.ts but simpler:

   Dependencies: feedbackRepository, reminderRepository, planRepository, sqlite, chatId, settings (ReminderSettings).

   Logic:
   - Get active plans (same as reminder generator)
   - Build date-to-meals map (same as reminder generator)
   - For each date in range (today through end):
     - If date has meals, schedule ONE feedback_checkin for the evening of that date
     - Check-in time: fixed at "20:30" (midpoint of 8-9pm window per user decision)
     - Use localTimeToUtc from generator.ts -- BUT since generator.ts doesn't export it, either duplicate the localTimeToUtc utility or extract it. **Decision: Extract localTimeToUtc and related helpers into a new shared location or duplicate inline.** Simplest: duplicate the localTimeToUtc function inline in feedback/generator.ts (it's ~20 lines, and keeping feedback self-contained is cleaner than refactoring reminders/generator.ts in this plan).
     - Consolidate multiple meals per day into a single check-in (per user decision)
     - Create a reminder with type "feedback_checkin" and contextJson containing the meals array
     - Also create a feedback_checkins tracking record linked to the reminder
     - Skip if a pending feedback_checkin reminder already exists for that time window (1-min dedup, same pattern as reminders/generator.ts)
     - Only create if due time is in the future

   The contextJson for the reminder should be:
   ```json
   {
     "date": "2026-02-10",
     "meals": [
       { "mealType": "dinner", "recipeName": "Chicken Parm", "knowledgeItemId": 42 }
     ]
   }
   ```

   Export: `generateFeedbackCheckins(deps: { feedbackRepository, reminderRepository, planRepository, sqlite, chatId, settings }): void`

2. **Create src/feedback/sender.ts** -- Send check-in messages via Telegram with inline buttons.

   Dependencies (minimal interfaces, same pattern as reminders/sender.ts):
   - BotApi (bot.api.sendMessage)
   - Logger

   `createFeedbackSender(deps: { bot: BotApi, logger: Logger })`

   The sender.sendCheckin(reminder, checkin) method:
   - Parse contextJson to get meals array
   - Build check-in message text:
     - Single meal: "How was the {recipeName} tonight?" (direct question naming the recipe, per user decision)
     - Multiple meals: "How was dinner tonight? You had {recipe1} and {recipe2}."
   - Build inline keyboard using buildFeedbackKeyboard(reminder.id)
   - Send via bot.api.sendMessage with parse_mode: "HTML" and reply_markup: keyboard
   - Return true on success, false on failure
   - NEVER throw -- catch all errors and log (same safety pattern as reminders/sender.ts)
   - On Telegram 403 (bot blocked), log and return false silently

   The message text should be warm and direct. Use HTML formatting. Examples:
   - "How was the <b>Chicken Parmesan</b> tonight?"
   - "How was dinner tonight? You had <b>Chicken Parm</b> and <b>Caesar Salad</b>."
