<task type="auto">
  <name>Task 2: Create grocery API routes and register in router</name>
  <files>
    src/mini-app/routes/grocery.ts
    src/mini-app/router.ts
  </files>
  <action>
1. Create `src/mini-app/routes/grocery.ts` following the `summary.ts` factory pattern exactly:
   - Import: `type { Request, Response }` from express, `type BetterSqlite3` from better-sqlite3, `createGroceryRepository` from `../../grocery/repository.js`, `guessSection` from `../../grocery/section-map.js`.
   - Export `createGroceryRoutes(sqlite: BetterSqlite3.Database)` returning an object with four handlers. Create repo inside: `const repo = createGroceryRepository(sqlite);`
   - All handlers read `const chatId = res.locals.chatId as string;`

   **getList** handler (for GET /api/grocery):
   - `repo.getActiveList(chatId)`. If null, return `res.json({ items: [], stores: [] })`.
   - `repo.getListItems(list.id)` to get items.
   - Derive stores: `const stores = [...new Set(items.map(i => i.store))]`
   - Return `res.json({ listId: list.id, items, stores })`

   **toggleItem** handler (for POST /api/grocery/toggle):
   - Read `const { itemId } = req.body`. If `typeof itemId !== 'number'`, return `res.status(400).json({ error: "itemId required" })`.
   - `const checked = repo.toggleItem(itemId)`.
   - Return `res.json({ itemId, checked })`

   **addItem** handler (for POST /api/grocery/add):
   - Read `const { name, quantity, store, section } = req.body`.
   - If `!name || typeof name !== 'string'`, return `res.status(400).json({ error: "name required" })`.
   - `const list = repo.getActiveList(chatId)`. If null, return `res.status(404).json({ error: "No active grocery list" })`.
   - Resolve section: `const resolvedSection = section || guessSection(name)`.
   - `repo.addItems(list.id, [{ name, quantity: quantity || undefined, store: store || 'Other', section: resolvedSection }])`.
   - Re-fetch: `const items = repo.getListItems(list.id)`.
   - Return `res.json({ items })`

   **completeList** handler (for POST /api/grocery/complete):
   - `repo.completeList(chatId)`.
   - Return `res.json({ ok: true })`

2. In `src/mini-app/router.ts`:
   - Add import: `import { createGroceryRoutes } from "./routes/grocery.js";`
   - Inside `createApiRouter`, after the summary route registration, add:
     ```
     const grocery = createGroceryRoutes(deps.sqlite);
     router.get("/grocery", grocery.getList);
     router.post("/grocery/toggle", grocery.toggleItem);
     router.post("/grocery/add", grocery.addItem);
     router.post("/grocery/complete", grocery.completeList);
     ```
  </action>

  </done>
