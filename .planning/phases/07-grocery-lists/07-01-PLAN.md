Create src/grocery/schema.ts with two Drizzle tables following the exact pattern of src/planning/schema.ts:

1. `groceryLists` table:
   - id: integer primary key autoincrement
   - chatId: text("chat_id") notNull
   - planId: integer("plan_id") -- optional soft link to meal_plans, NO foreign key constraint
   - messageId: integer("message_id") -- stores Telegram message ID for in-place editing
   - status: text("status", { enum: ["draft", "active", "completed"] }) notNull default "active"
   - createdAt: integer("created_at", { mode: "timestamp" }) notNull $defaultFn(() => new Date())
   - updatedAt: integer("updated_at", { mode: "timestamp" }) notNull $defaultFn(() => new Date())

2. `groceryListItems` table:
   - id: integer primary key autoincrement
   - listId: integer("list_id") notNull references groceryLists.id onDelete cascade
   - name: text("name") notNull
   - quantity: text("quantity") -- freeform text like "2 lbs", "3", "1 bunch" (nullable)
   - store: text("store") notNull -- user-defined store name, NOT an enum
   - section: text("section") notNull -- "Produce", "Dairy", "Meat", etc. NOT an enum (user-configurable)
   - checked: integer("checked", { mode: "boolean" }) notNull default false
   - createdAt: integer("created_at", { mode: "timestamp" }) notNull $defaultFn(() => new Date())

  <action>
Create src/grocery/repository.ts with createGroceryRepository factory function following the pattern of src/planning/repository.ts.

The repository takes raw better-sqlite3 instance (for raw SQL JOINs, consistent with the preferences and plan handler patterns) plus the Drizzle db instance.

Exported types:
- GroceryItem: { id, listId, name, quantity, store, section, checked, createdAt }
- GroceryList: { id, chatId, planId, messageId, status, createdAt, updatedAt }
- NewGroceryItem: { name, quantity?, store, section }

Factory function createGroceryRepository(sqlite: BetterSqlite3.Database) returns object with methods:

1. createList(chatId: string, planId?: number): GroceryList
   - Deactivate any existing active list for this chat (set status = 'completed')
   - INSERT new grocery_lists row with status 'active'
   - Return the created list

2. getActiveList(chatId: string): GroceryList | null
   - SELECT from grocery_lists WHERE chat_id = ? AND status = 'active' ORDER BY created_at DESC LIMIT 1

3. getListItems(listId: number): GroceryItem[]
   - SELECT from grocery_list_items WHERE list_id = ? ORDER BY store, section, name

4. addItems(listId: number, items: NewGroceryItem[]): void
   - Batch INSERT items into grocery_list_items

5. removeItems(itemIds: number[]): void
   - DELETE FROM grocery_list_items WHERE id IN (...)

6. toggleItem(itemId: number): boolean
   - UPDATE grocery_list_items SET checked = NOT checked WHERE id = ?
   - Return the new checked state

7. checkItems(itemIds: number[]): void
   - UPDATE grocery_list_items SET checked = 1 WHERE id IN (...)

8. uncheckItems(itemIds: number[]): void
   - UPDATE grocery_list_items SET checked = 0 WHERE id IN (...)

9. setMessageId(listId: number, messageId: number): void
   - UPDATE grocery_lists SET message_id = ?, updated_at = unixepoch() WHERE id = ?

10. getListIdForItem(itemId: number): number | null
    - SELECT list_id FROM grocery_list_items WHERE id = ?

All queries use raw SQL via sqlite.prepare().run() / .get() / .all() (same pattern as fts.ts, preferences.ts, history.ts). NOT Drizzle queries.

IMPORTANT: Use .js extensions on all local imports.
