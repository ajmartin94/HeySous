**2. Make getWeekStartDate timezone-aware (src/planning/date-utils.ts)**

Change `getWeekStartDate` to accept an optional `dateStr` parameter (ISO "YYYY-MM-DD" string representing today in the user's timezone) instead of an optional Date:

```typescript
export function getWeekStartDate(dateStr?: string): string {
  const d = dateStr ? new Date(dateStr + "T00:00:00") : new Date();
  const jsDay = d.getDay();
  const daysSinceMonday = (jsDay + 6) % 7;
  d.setDate(d.getDate() - daysSinceMonday);
  return formatIsoDate(d);
}
```

This is backward-compatible -- existing calls with no argument still work (using server time as fallback), but callers can pass in a timezone-resolved "today" string to get correct results.
