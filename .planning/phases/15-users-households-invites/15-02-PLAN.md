**src/bot/handlers/start.ts** -- Complete rewrite from simple greeting to invite-aware handler:
- Change from static Composer export to factory function: `export function createStartHandler(deps: StartHandlerDeps): Composer<BotContext>`
- Deps interface: `{ sqlite: BetterSqlite3.Database, addToCache: (user: User) => void }` -- addToCache is from the access gate to immediately cache newly registered users
- Import: getUserByTelegramId, createUser, updateHouseholdName, getAdmin from users/repository, getAndRedeemToken from invites/repository, BotContext, User type, logger
- Handler for `command("start")` implementing 4-way branch per RESEARCH.md Pattern 3:

  **Branch 1 -- Existing user, no token (bare /start):**
  - Check `getUserByTelegramId(deps.sqlite, telegramId)`. If found and `!ctx.match` (no deep link payload):
  - Reply: "Welcome back! What can I help you with?"

  **Branch 2 -- Existing user, with token:**
  - If found and `ctx.match` is truthy:
  - Ignore the token (don't re-register). Reply: "Welcome back! What can I help you with?"
  - (User is already registered, they just clicked an invite link while already in the system)

  **Branch 3 -- New user, valid token:**
  - If not found and `ctx.match` is truthy:
  - Call `getAndRedeemToken(deps.sqlite, ctx.match, telegramId)`. If returns token:
  - Determine householdId: use `token.householdId` (already resolved by the token's association)
  - Create user via `createUser(deps.sqlite, { telegramId, displayName: ctx.from!.first_name, username: ctx.from!.username ?? null, householdId: token.householdId, role: 'member', onboardingState: 'complete' })`
  - Call `deps.addToCache(newUser)` to immediately cache the new user
  - Call `updateHouseholdName(deps.sqlite, token.householdId)` to auto-update household name from member names
  - Send warm greeting (per locked decision -- warm Claude greeting with personality):
    `"Hey ${displayName}! Welcome to HeySous! I'm your meal planning assistant -- I remember recipes, plan weekly dinners, build grocery lists, and send prep reminders. Tell me about a recipe you love, or ask me to plan your week!"`
  - Notify admin (per locked decision): Get admin via `getAdmin(deps.sqlite)`. If admin exists and admin.telegramId !== telegramId, send message to admin: `"${displayName} just joined your household!"` via `ctx.api.sendMessage(admin.telegramId, message)`
  - If getAndRedeemToken returns null (token invalid/expired/used): fall through to Branch 4

  **Branch 4 -- New user, no token or invalid token:**
  - If not found and (`!ctx.match` or token redemption failed):
  - If ctx.match was truthy but token was invalid: "This invite link is no longer valid. Ask for a new one!" (per locked decision)
  - If no token at all: "Hey! I'm an invite-only bot. Ask the person who told you about me for an invite link!" (per locked decision)

**src/bot/handlers/invite.ts** -- New file, factory function pattern:
- `export function createInviteHandler(deps: InviteHandlerDeps): Composer<BotContext>`
- Deps interface: `{ sqlite: BetterSqlite3.Database, botUsername: string }`
- Import: Composer from grammy, BotContext, createInviteToken and generateToken from invites/repository, generateDeepLink from invites/deep-link, createHousehold and getHouseholdById from users/repository, logger, crypto (for randomUUID for independent household IDs)
- Handler for `command("invite")`:
  1. Admin check: `if (ctx.user?.role !== 'admin') return` (silent rejection for non-admins, same pattern as /costs)
  2. Parse flags from `ctx.match` (the text after `/invite`):
     - No args (empty string) -> default: join admin's household. `targetHouseholdId = ctx.user.householdId`
     - `"independent"` -> create new solo household. Generate ID with `crypto.randomUUID()`, create household with name "New Household", createdBy = ctx.user.telegramId. Set inviteType = 'independent'.
     - Starts with `"household:"` -> join specific household. Extract ID after prefix. Look up via `getHouseholdById`. If not found, reply "Household not found." and return. Set inviteType = 'household'.
     - Any other text -> reply with usage help: "Usage: /invite, /invite independent, or /invite household:ID"
  3. Generate token: `const token = generateToken()`
  4. Calculate expiry: `Math.floor(Date.now() / 1000) + 7 * 24 * 60 * 60` (7 days in unix seconds)
  5. Create invite: `createInviteToken(deps.sqlite, { token, householdId: targetHouseholdId, inviteType, createdBy: ctx.user.telegramId, expiresAt: expiry })`
  6. Build URL: `generateDeepLink(deps.botUsername, token)`
  7. Reply: `"Invite link (expires in 7 days, single use):\n\n${url}\n\nShare this with the person you want to invite."`
  8. Log: `logger.info({ householdId: targetHouseholdId, inviteType }, "Invite created")`

Note: Use `import { randomUUID } from "node:crypto"` for household ID generation (independent invites).
