**3. Create `src/knowledge/url-import.ts`:**

This is the core extraction module. Structure:

```typescript
import * as cheerio from "cheerio";
import { logger } from "../logger.js";

/** Maximum response size (2MB) */
const MAX_RESPONSE_SIZE = 2 * 1024 * 1024;

/** HTTP fetch timeout (10 seconds) */
const FETCH_TIMEOUT_MS = 10_000;

/** Browser-like User-Agent to avoid anti-scraping blocks */
const USER_AGENT = "Mozilla/5.0 (compatible; HeySous/1.0; recipe-import)";

export interface ExtractedRecipe {
  title: string;
  ingredients: string[];
  instructions: string[];
  prepTime?: string;
  cookTime?: string;
  totalTime?: string;
  servings?: string;
  description?: string;
  sourceUrl: string;
  extractionMethod: "json-ld" | "microdata" | "raw-text";
}

export interface ImportResult {
  success: boolean;
  recipe?: ExtractedRecipe;
  rawText?: string;
  error?: string;
  suggestion?: string;
}
```

Then implement:

**a) `fetchAndParseRecipe(url: string): Promise<ImportResult>`** -- main entry point:
- Validate URL (must start with http:// or https://)
- Fetch with `AbortSignal.timeout(FETCH_TIMEOUT_MS)`, User-Agent header, Accept: text/html
- Check Content-Type is text/html (reject PDFs, images, etc.)
- Read response text with 2MB size check
- Try JSON-LD extraction first
- Try Microdata extraction second
- Fall back to raw text truncation (first ~4000 chars) for Claude to parse
- Catch all errors and return helpful messages

**b) `extractJsonLd(html: string, url: string): ExtractedRecipe | null`** -- Strategy A:
- Load HTML with cheerio
- Find all `script[type="application/ld+json"]` elements
- Parse each as JSON
- Handle `@graph` arrays (flatten and find `@type: "Recipe"`)
- Handle arrays at top level
- Handle `@type` being string or array (some sites use `["Recipe", "HowTo"]`)
- Extract: name, recipeIngredient, recipeInstructions, prepTime, cookTime, totalTime, recipeYield, description
- Normalize `recipeInstructions` which can be: string, string[], or `{@type: "HowToStep", text: string}[]`
- Parse ISO 8601 durations (PT1H30M -> "1 hour 30 minutes")
- Strip HTML from text fields
- Clean title (remove " - Site Name" suffixes)

**c) `extractMicrodata(html: string, url: string): ExtractedRecipe | null`** -- Strategy B:
- Load HTML with cheerio
- Find element with `itemtype` containing "schema.org/Recipe"
- Extract `itemprop="name"`, `itemprop="recipeIngredient"`, `itemprop="recipeInstructions"` etc.
- Same normalization as JSON-LD

**d) Helper functions:**
- `parseIsoDuration(iso: string): string` -- Convert "PT1H30M" to "1 hour 30 minutes"
- `stripHtml(html: string): string` -- Remove HTML tags, decode entities
- `cleanTitle(title: string): string` -- Remove SEO suffixes
- `normalizeInstructions(raw: unknown): string[]` -- Handle all instruction formats

**1. Update `src/ai/claude-client.ts` to support async onToolCall:**

Change the `onToolCall` parameter type in `sendMessageWithTools`:
```typescript
// Before:
onToolCall: (name: string, input: Record<string, unknown>) => string,
// After:
onToolCall: (name: string, input: Record<string, unknown>) => string | Promise<string>,
```

Update the tool results mapping to use `Promise.all`:
```typescript
// Before:
const toolResults: Anthropic.ToolResultBlockParam[] =
  toolUseBlocks.map((block) => {
    try {
      const result = onToolCall(block.name, block.input as Record<string, unknown>);
      return { ... };
    } catch (error) {
      return { ... };
    }
  });

// After:
const toolResults: Anthropic.ToolResultBlockParam[] =
  await Promise.all(
    toolUseBlocks.map(async (block) => {
      try {
        const result = await onToolCall(block.name, block.input as Record<string, unknown>);
        return {
          type: "tool_result" as const,
          tool_use_id: block.id,
          content: result,
        };
      } catch (error) {
        const errorMessage = error instanceof Error ? error.message : String(error);
        return {
          type: "tool_result" as const,
          tool_use_id: block.id,
          content: JSON.stringify({ error: errorMessage }),
          is_error: true,
        };
      }
    })
  );
```

RECIPE IMPORT:
When a user shares a URL that appears to be a recipe link:
1. Call import_from_url with the URL
2. If extraction succeeds, present the recipe to the user in a clean format (title, ingredients, instructions, times)
3. Ask the user to confirm before saving: "Here's what I found! Want me to save this to your recipes?"
4. If the user confirms, call save_knowledge with the extracted content and include source_url
5. If extraction returns raw_text (fallback), use the text to identify the recipe yourself and present it

If the import fails:
- Suggest alternatives based on the error (paste the text, send a photo, check the URL)
- Do NOT retry the same URL repeatedly

When a URL is shared mid-conversation (not as a standalone message):
- Offer to import: "I see a recipe link! Want me to grab that recipe for you?"
- Do NOT auto-import without asking

IMPORTANT: Always show the extracted recipe to the user for confirmation before saving.
The user may want to adjust the title, ingredients, or instructions before saving.
