<objective>
Restructure the system prompt for Anthropic API prompt caching by separating static instructions from dynamic household context.

Purpose: The Anthropic API caches system prompt content marked with `cache_control: { type: "ephemeral" }`. Currently the entire prompt (static + dynamic) is one block, so any change in dynamic context (which changes every request) invalidates the cache. By splitting into a stable static prefix (with cache_control) and a dynamic suffix (without), ~91% of the prompt tokens get cached at 90% reduced input cost per cached token.

Output: Refactored prompt builder with separate static/dynamic functions, updated Claude client supporting two-block system parameter, processor wiring both together.
</objective>

   When a `SystemPromptInput` object is provided, build TWO system blocks:
   ```typescript
   const systemBlocks = typeof systemPromptInput === 'string'
   ```
