**src/bot/handlers/reminders.ts** -- Create /reminders command handler (same factory pattern as grocery.ts handler):

Create `createRemindersHandler(sqlite: BetterSqlite3.Database): Composer<BotContext>`

The handler:
1. Creates a local `reminderRepository` via `createReminderRepository(sqlite)` (same pattern as grocery handler creates groceryRepository)
2. Registers `handler.command("reminders", async (ctx) => { ... })`
3. Gets chatId from `String(ctx.chat.id)`
4. Calls `reminderRepository.getOrCreateSettings(chatId)` -- creates defaults if first time
5. Formats a clean HTML response showing current settings:

```
<b>Reminder Settings</b>

Morning summary: {ON/OFF} (at {morningTime})
Prep alerts: {ON/OFF}
Dinner time: {dinnerTime}
Timezone: {timezone}
{If mutedUntil and mutedUntil > now: "\nMuted until {formatted date}"}

<i>Tip: You can change these in conversation too -- just tell me!</i>
```

6. Sends the formatted response via `ctx.reply(formatted, { parse_mode: "HTML" })`

No admin restriction on /reminders -- any user can view their own settings (matches /preferences and /debug pattern per existing codebase decisions).
