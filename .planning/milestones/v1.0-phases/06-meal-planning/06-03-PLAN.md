<task type="auto">
  <name>Task 1: /plan command handler</name>
  <files>src/bot/handlers/plan.ts</files>
  <action>
Create `src/bot/handlers/plan.ts` following the exact pattern of `src/bot/handlers/preferences.ts`:

1. Import Composer from "grammy", type BetterSqlite3 from "better-sqlite3", type BotContext from "../context.js", sendFormattedMessage from "../../telegram/sender.js", getWeekStartDate and DAY_NAMES and formatDateRange from "../../planning/date-utils.js".

2. Define a local interface `PlanRow` for the raw SQLite query results: { recipe_name: string; day_of_week: number; meal_type: string }.

3. Create a local function `getCurrentWeekPlan(sqlite: BetterSqlite3.Database, chatId: string): PlanRow[]` that uses raw SQLite (same pattern as getPreferenceSummaries):
   ```sql
   SELECT mpe.recipe_name, mpe.day_of_week, mpe.meal_type
   FROM meal_plans mp
   JOIN meal_plan_entries mpe ON mpe.plan_id = mp.id
   WHERE mp.chat_id = ? AND mp.week_start_date = ?
   ORDER BY mpe.day_of_week ASC, mpe.meal_type ASC
   ```
   Pass chatId and getWeekStartDate() as parameters.

4. Create a local function `formatPlanMessage(entries: PlanRow[], weekStartDate: string): string`:
   - Check if all entries are dinner-only (every entry has meal_type === "dinner")
   - Header: `<b>This Week's Plan</b>\n<i>{formatDateRange(weekStartDate)}</i>`
   - If dinner-only: one line per entry: `{DayName} - {recipeName}` using DAY_NAMES[entry.day_of_week]
   - If multi-meal: group by day, show `<b>{DayName}</b>` header, then lines like `Breakfast - {recipeName}`
   - Join all lines with newlines

5. Export `createPlanHandler(sqlite: BetterSqlite3.Database): Composer<BotContext>`:
   - Create a new Composer<BotContext>()
   - Register `.command("plan", async (ctx) => { ... })`
   - Get chatId from String(ctx.chat.id)
   - Call getCurrentWeekPlan(sqlite, chatId)
   - If no entries: reply with "No meal plan for this week yet! Just say something like \"plan my dinners for this week\" and we'll figure it out together."
   - If entries found: format with formatPlanMessage and send via sendFormattedMessage
   - Return the composer

No admin restriction (matches /preferences and /debug patterns).
