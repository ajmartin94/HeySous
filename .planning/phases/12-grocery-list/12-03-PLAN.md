1. Create `mini-app/src/hooks/useMainButton.ts`:
   - Import `mainButton` from `@tma.js/sdk-react` and `useEffect`, `useCallback` from `react`.
   - Export `useMainButton(text: string, onClick: () => void, enabled: boolean = true)`:
     - In useEffect: call `mainButton.mount()`, then `mainButton.setParams({ text, isVisible: true, isEnabled: enabled })`.
     - Subscribe: `const off = mainButton.onClick(onClick)`.
     - Cleanup: `off()`, `mainButton.hide()`, `mainButton.unmount()`.
     - Dependencies: [text, onClick, enabled].
   - Also export helper functions from the hook return: `{ showLoader, hideLoader }` that call `mainButton.setParams({ isLoaderVisible: true/false })`.

2. Enhance `mini-app/src/hooks/useGroceryList.ts` -- add to the existing hook:
   - Add `addItem(name: string, quantity: string | undefined, store: string): Promise<void>` to the returned object:
     - POST to `/grocery/add` with `{ name, quantity, store, section: undefined }` (server auto-assigns section).
     - On success, update items from the response `{ items }`.
     - On failure, set error state briefly.
   - Add `completeList(): Promise<boolean>` to the returned object:
     - POST to `/grocery/complete`.
     - On success, return true. On failure, return false.
   - Add polling: accept an optional `pollInterval` parameter (default 0 = disabled). When non-zero, set up a `setInterval` that calls refetch. Clean up on unmount. Also add a `visibilitychange` event listener that refetches when the document becomes visible (user switches back to Mini App tab). Use `useEffect` for both.
   - Export the `GroceryItem` interface type from this file so components can import it.

       - Note below: "Adding to {activeStore}" in hint color.

       - Set submitting true.
       - Call `onAdd(name.trim(), quantity.trim() || undefined, activeStore)`.
       - On success: clear name and quantity fields (form stays open per user decision -- for rapid multiple adds).
       - Set submitting false.
     - On close (backdrop tap or explicit X button): set isOpen false, clear fields.
