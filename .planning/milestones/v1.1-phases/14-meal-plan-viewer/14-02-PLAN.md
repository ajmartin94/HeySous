Replace the placeholder `MealPlan.tsx` with the full meal plan viewer. This is the main orchestration component that wires everything together. Follow the `Recipes.tsx` pattern closely.

**Imports:**
- `useState, useEffect, useRef` from react
- `backButton` from `@tma.js/sdk-react`
- `useSwipeable` from `react-swipeable`
- `useMealPlan` from `../hooks/useMealPlan.js`
- `WeekHeader` from `../components/meal-plan/WeekHeader.js`
- `DayRow` from `../components/meal-plan/DayRow.js`
- `RecipeDetail` from `../components/recipes/RecipeDetail.js`
- `SkeletonCard` from `../components/SkeletonCard.js`
- `getTodayIndex, isPastDay` from `../utils/dateUtils.js`
- `../components/meal-plan/meal-plan.css`

**Component structure:**

1. **Hook usage:**
   ```typescript
   const {
     activeWeek, activeWeekIndex, setActiveWeekIndex,
     loading, error,
     selectedRecipeId, recipeDetail, detailLoading,
     openDetail, closeDetail,
   } = useMealPlan();
   ```

2. **Scroll position preservation** (same pattern as Recipes.tsx):
   ```typescript
   const scrollPositionRef = useRef(0);
   const todayRef = useRef<HTMLDivElement>(null);
   ```

3. **BackButton override for detail view** (exact pattern from Recipes.tsx):
   - When `selectedRecipeId !== null`, register backButton.onClick to call `handleCloseDetail`.
   - Use `isAvailable()` guard.
   - Return cleanup function.

4. **handleOpenDetail(knowledgeItemId: number):**
   - Save `window.scrollY` to `scrollPositionRef.current`.
   - Call `openDetail(knowledgeItemId)`.

5. **handleCloseDetail():**
   - Call `closeDetail()`.
   - Use `requestAnimationFrame` to restore scroll position from `scrollPositionRef.current`.

6. **Swipe navigation** using `useSwipeable`:
   ```typescript
   const swipeHandlers = useSwipeable({
     onSwipedLeft: () => {
       if (activeWeekIndex === 0) setActiveWeekIndex(1);
     },
     onSwipedRight: () => {
       if (activeWeekIndex === 1) setActiveWeekIndex(0);
     },
     delta: 50,
     trackTouch: true,
     trackMouse: false,
     swipeDuration: 500,
   });
   ```

7. **Auto-scroll to today on initial load:**
   ```typescript
   useEffect(() => {
     if (!loading && activeWeekIndex === 0 && todayRef.current) {
       requestAnimationFrame(() => {
         todayRef.current?.scrollIntoView({ behavior: 'smooth', block: 'start' });
       });
     }
   }, [loading]);
   ```
   Only auto-scroll for the current week (activeWeekIndex === 0) on first load.

8. **Render logic (3 branches like Recipes.tsx):**

   **Branch A -- RecipeDetail view** (when `selectedRecipeId !== null`):
   - If `detailLoading || !recipeDetail`, show SkeletonCard(lines=6) wrapped in meal-plan-page div.
   - Otherwise show `<RecipeDetail recipe={recipeDetail} onBack={handleCloseDetail} />`.

   **Branch B -- Loading state** (when `loading`):
   - Show WeekHeader + 7 SkeletonCards in a column.

   **Branch C -- Week view** (default):
   - Wrap in `<div {...swipeHandlers} className="meal-plan-page">`.
   - Render `<WeekHeader activeWeekIndex={activeWeekIndex} />`.
   - Add a `<div className="week-content">` container.
   - If `activeWeek` is null or has no entries, render all 7 days as empty (using DayRow with empty entries array).
   - Otherwise, for each `dayOfWeek` 0-6:
     - Filter `activeWeek.entries` to this day.
     - Compute `isToday = activeWeekIndex === 0 && dayOfWeek === getTodayIndex()`.
     - Compute `isPast = isPastDay(dayOfWeek, activeWeekIndex === 0)`.
     - Render `<DayRow>` with appropriate props.
     - Pass `todayRef` to the day that isToday.

   **Error state:** If `error` is set and not loading, show a simple error message.

- Vertical stack orientation -- days stacked top-to-bottom (each DayRow is full-width)

- Swipe between weeks (useSwipeable with delta: 50)
- Week header shows "This Week" / "Next Week" only (handled by WeekHeader)
- Auto-scroll to today on open (useEffect + todayRef)
- Today's day row gets accent background (CSS class day-row--today)
- Empty week shows 7-day grid structure with no meals
- Past days dimmed (CSS class day-row--past)
- Meals without recipe show "no recipe" indicator, not tappable (MealEntry)
- Meal type icons: Sunrise/Sun/Moon (MealEntry)
- Always show meal type label even for single meal (MealEntry)
- Only show meal types that have entries (no empty meal type rows)
