<objective>
Detect context window overflow before the Anthropic API call and gracefully degrade by trimming oldest conversation history. When trimming occurs, inject an internal notice for Claude without surfacing it to the user.

Purpose: Long conversations can accumulate enough tokens to exceed or approach the model's context window. Rather than failing at the API level or getting degraded responses, the pipeline should proactively detect this and trim oldest messages first, giving Claude a notice that some history was omitted so it can continue naturally.

Output: Updated context builder with trimming metadata, updated processor with pre-call estimation and graceful degradation, truncation notice in dynamic context.
</objective>

3. After constructing `fullMessages` (step f) and the `systemPrompt` (after step h), add a pre-call token estimation check:

   ```typescript
   // i0. Estimate total token count and check for context overflow
   const estimatedSystemTokens = estimateTokens(staticPrompt) + estimateTokens(dynamicContext);
   const estimatedMessageTokens = estimateMessageTokens(fullMessages);
   const estimatedTotalTokens = estimatedSystemTokens + estimatedMessageTokens;

   let contextTrimmed = wasTruncated;

   if (estimatedTotalTokens > CONTEXT_WINDOW_TOKENS * CONTEXT_TRIM_THRESHOLD) {
     // Context approaching limit -- aggressively trim conversation history
     log.warn(
       {
         chatId,
         householdId,
         estimatedTotalTokens,
         threshold: CONTEXT_WINDOW_TOKENS * CONTEXT_TRIM_THRESHOLD,
         priorMessageCount: priorMessages.length,
       },
       "Context approaching window limit, trimming conversation history",
     );

     // Remove oldest messages from priorMessages until under threshold
     // This trims from fullMessages (which has priorMessages + current user message)
     while (fullMessages.length > 1) { // Always keep at least the current user message
       const currentEstimate = estimateTokens(staticPrompt) + estimateTokens(dynamicContext) + estimateMessageTokens(fullMessages);
       if (currentEstimate <= CONTEXT_WINDOW_TOKENS * CONTEXT_TRIM_THRESHOLD) {
         break;
       }
       // Remove the oldest message (first element, which is oldest conversation history)
       fullMessages.shift();
       contextTrimmed = true;
     }

     // If still over after removing all history, log and proceed anyway
     // (the API will handle it, or the request is genuinely too large)
     const finalEstimate = estimateTokens(staticPrompt) + estimateTokens(dynamicContext) + estimateMessageTokens(fullMessages);
     if (finalEstimate > CONTEXT_WINDOW_TOKENS * CONTEXT_TRIM_THRESHOLD) {
       log.warn(
         {
           chatId,
           householdId,
           estimatedTokens: finalEstimate,
           threshold: CONTEXT_WINDOW_TOKENS * CONTEXT_TRIM_THRESHOLD,
         },
         "Context still over threshold after trimming all history -- proceeding with current message only",
       );
     }
   }
   ```
