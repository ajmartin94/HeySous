Create `mini-app/vite.config.ts`:
- Import defineConfig from vite, react from @vitejs/plugin-react
- Set `base: '/app/'` (CRITICAL -- Pitfall 4: must match Express mount and router basename)
- Set `plugins: [react()]`
- Set `build.outDir: 'dist'` and `build.emptyOutDir: true`
- Add dev proxy: `server.proxy['/api']` targeting `http://localhost:3000` with `changeOrigin: true`

Create `mini-app/src/init.ts`:
- Import from `@tma.js/sdk-react`: init, miniApp, themeParams, viewport, swipeBehavior, backButton
- Export async function `initializeTelegramSDK()`:
  1. `init()` -- must be first
  2. `themeParams.mount()` then `miniApp.mount()` -- mount components
  3. `themeParams.bindCssVars()` then `miniApp.bindCssVars()` -- bind CSS variables (INFRA-06)
  4. `await viewport.mount()` then `viewport.bindCssVars()` -- mount viewport (async!)
  5. `viewport.expand()` -- expand to full height (INFRA-05)
  6. If `swipeBehavior.mount.isAvailable()`: call `swipeBehavior.mount()` then `swipeBehavior.disableVertical()` -- iOS scroll collapse fix (INFRA-05, Pitfall 1)
  7. `backButton.mount()` -- mount back button for navigation
  8. `miniApp.ready()` -- signal ready, hides loading placeholder

Create `mini-app/src/api.ts`:
- Import `retrieveLaunchParams` from `@tma.js/sdk-react`
- Call `retrieveLaunchParams()` ONCE at module level, store `initDataRaw` (Pitfall 3: hash overwritten by router)
- Export async function `apiFetch(path: string, options?: RequestInit): Promise<Response>`:
  - Fetches `/api${path}` with merged headers including `Content-Type: application/json` and `X-Init-Data: initDataRaw ?? ""`
  - Returns the fetch Response
