**src/mini-app/routes/memory.ts** -- Create API routes:
- `createMemoryRoutes(sqlite)` returns `{ getAll, deleteOne }`
- `getAll`: GET handler -- reads `res.locals.householdId`, calls `getMemoriesByHousehold(sqlite, householdId)`, returns JSON array grouped by category: `{ categories: [{ name: "dietary", memories: [{id, content}] }, ...] }`
- `deleteOne`: DELETE handler -- reads `req.params.id` and `res.locals.householdId`, calls `deleteMemory(sqlite, id, householdId)`, returns 200 on success or 404

**src/mini-app/routes/settings.ts** -- Create API routes:
- `createSettingsRoutes(sqlite)` returns `{ getSettings, updateSettings }`
- `getSettings`: GET handler -- reads `res.locals.householdId`, queries `application_settings` table for that household. Returns JSON with timezone, morning_time, breakfast_time, lunch_time, snack_time, dinner_time, dessert_time, morning_enabled, prep_alerts_enabled, muted_until.
- `updateSettings`: PUT handler -- reads `res.locals.householdId` and `req.body` (partial settings object), updates only provided fields in `application_settings`. Uses an UPDATE with SET for each provided field. Returns updated settings.

**src/mini-app/router.ts** -- Register new routes:
```typescript
const memory = createMemoryRoutes(deps.sqlite);
router.get("/memories", memory.getAll);
router.delete("/memories/:id", memory.deleteOne);

const settings = createSettingsRoutes(deps.sqlite);
router.get("/settings", settings.getSettings);
router.put("/settings", settings.updateSettings);
```

Import from `./routes/memory.js` and `./routes/settings.js`.
