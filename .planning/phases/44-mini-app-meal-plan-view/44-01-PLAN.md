**1. Add collapse state management to MealPlan.tsx:**

Add a `useState` for tracking which days are collapsed. Per the user's decision, default state is ALL EXPANDED:

```typescript
const [collapsedDays, setCollapsedDays] = useState<Set<number>>(new Set());

const toggleDay = useCallback((dayOfWeek: number) => {
  setCollapsedDays(prev => {
    const next = new Set(prev);
    if (next.has(dayOfWeek)) {
      next.delete(dayOfWeek);
    } else {
      next.add(dayOfWeek);
    }
    return next;
  });
}, []);
```

Pass `isCollapsed` (boolean) and `onToggle` callback to each DayRow:
