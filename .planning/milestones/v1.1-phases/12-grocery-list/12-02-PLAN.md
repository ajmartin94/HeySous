1. Create `mini-app/src/hooks/useHaptic.ts`:
   - Import `hapticFeedback` from `@tma.js/sdk-react`.
   - Export `useHaptic()` returning `{ tap }` where `tap` is a function that calls `hapticFeedback.notificationOccurred('success')` wrapped in a try/catch (graceful no-op outside Telegram). Use `notificationOccurred('success')` instead of `impactOccurred('light')` because impactOccurred doesn't work on Android (Pitfall 3 from research).

2. Create `mini-app/src/hooks/useGroceryList.ts`:
   - Import `apiFetch` from `../api.js`.
   - Import the `GroceryItem` interface type -- define it locally in this file since it mirrors the server type:
     ```
     interface GroceryItem {
       id: number; listId: number; name: string; quantity: string | null;
       store: string; section: string; checked: boolean; createdAt: string;
     }
     ```
   - Export `useGroceryList()` hook returning:
     - `items: GroceryItem[]` -- all items for active list
     - `stores: string[]` -- unique store names from API
     - `loading: boolean` -- true during initial fetch
     - `error: string | null`
     - `toggleItem: (itemId: number) => void` -- optimistic toggle
     - `refetch: () => void` -- manual refetch trigger
     - `hasActiveList: boolean` -- true if API returned a listId
   - On mount (useEffect with empty deps): call `apiFetch('/grocery')`, parse JSON, set items + stores. Set loading false. Handle errors.
   - `toggleItem` implementation:
     - Optimistically update items state: flip the `checked` boolean for the matching itemId.
     - Fire-and-forget `apiFetch('/grocery/toggle', { method: 'POST', body: JSON.stringify({ itemId }) })`.
     - On failure, revert: flip the checked boolean back. Set a brief error message.
   - `refetch`: re-calls the GET endpoint and replaces items state.
   - Do NOT add polling in this plan (Plan 03 adds it).
