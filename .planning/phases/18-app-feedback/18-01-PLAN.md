Create the `src/app-feedback/` module with three files following existing module patterns (e.g., `src/feedback/`):

**types.ts:**
- `AppFeedbackSource` type: `"command" | "implicit" | "mini-app" | "proactive"`
- `AppFeedback` interface: `{ id: number; householdId: string; userId: string; text: string; source: AppFeedbackSource; createdAt: number }`
- `SaveFeedbackParams` interface: `{ householdId: string; userId: string; text: string; source: AppFeedbackSource }`

**init.ts:**
- Export `initializeAppFeedback(sqlite: BetterSqlite3.Database): void`
- Create two tables via `sqlite.exec()`:
  1. `app_feedback`: id (INTEGER PK AUTOINCREMENT), household_id (TEXT NOT NULL), user_id (TEXT NOT NULL), text (TEXT NOT NULL), source (TEXT NOT NULL CHECK IN command/implicit/mini-app/proactive), created_at (INTEGER NOT NULL DEFAULT unixepoch())
  2. `app_feedback_prompt_tracking`: household_id (TEXT PRIMARY KEY), last_prompt_at (INTEGER NOT NULL DEFAULT 0), messages_at_last_prompt (INTEGER NOT NULL DEFAULT 0)
- Use CREATE TABLE IF NOT EXISTS for both (idempotent)

**repository.ts:**
- Export `createAppFeedbackRepository(sqlite: BetterSqlite3.Database)` returning object with:
  1. `saveFeedback(params: SaveFeedbackParams): void` -- INSERT INTO app_feedback
  2. `getMessageCountSinceLastPrompt(householdId: string): number` -- query app_feedback_prompt_tracking for messages_at_last_prompt, then COUNT(*) from messages WHERE chat_id = householdId AND direction = 'in', return difference
  3. `recordProactivePromptShown(householdId: string): void` -- get current total inbound message count, INSERT OR REPLACE into app_feedback_prompt_tracking

**db/index.ts:**
- Import `initializeAppFeedback` from `../app-feedback/init.js`
- Add `initializeAppFeedback(sqlite)` call after `initializeInvites(sqlite)` at the bottom

**bot/handlers/app-feedback.ts:**
- Export `createAppFeedbackHandler(sqlite: BetterSqlite3.Database): Composer<BotContext>`
- Follow the exact same factory pattern as `createRemindersHandler`
- Handle `/feedback` command:
  - Extract text via `ctx.match` (grammY gives text after /feedback automatically)
  - If empty/whitespace, reply: `"Just type /feedback followed by your thoughts!"` and return
  - Otherwise, call `repository.saveFeedback({ householdId: ctx.householdId!, userId: ctx.userId!, text: text.trim(), source: "command" })`
  - Reply: `"Thanks for the feedback!"` (per user decision -- simple, short, warm, no echo-back)
- Use .js extensions on all imports

All files must use ESM with .js import extensions, match existing code style (no semicolons in some patterns vs with semicolons -- follow what exists in similar files).

Wire the app feedback system into the Claude AI pipeline, proactive prompt mechanism, and bot registration.

**src/ai/tools.ts:**
- Add a new `APP_FEEDBACK_TOOLS` export after the existing `FEEDBACK_TOOLS` array
- Single tool `save_app_feedback`:
  - name: `"save_app_feedback"`
  - description: `"Silently save app-related feedback detected in conversation. Use when the user expresses opinions about the bot's features, UX, or experience (e.g., 'I wish you could...', 'the grocery list feature is great', 'it's annoying when...'). Do NOT acknowledge saving feedback to the user. Do NOT use for meal/recipe feedback. Do NOT use for general frustration unrelated to bot features."`
  - input_schema: object with required `text` (string) property

**src/ai/tool-handler.ts:**
- Add `appFeedbackRepository` as an optional dependency in the `createToolHandler` deps interface (type: `ReturnType<typeof createAppFeedbackRepository>` -- import the type)
- Add a `case "save_app_feedback"` in the switch:
  - If no appFeedbackRepository, return JSON error
  - Extract text from input
  - Call `appFeedbackRepository.saveFeedback({ householdId, userId: householdId, text, source: "implicit" })` (use householdId as userId since implicit detection happens at conversation level, not per-user)
  - Return `JSON.stringify({ saved: true })`

**src/ai/system-prompt.ts:**
- Add a new `APP_FEEDBACK_PROMPT` constant with instructions for implicit detection and proactive feedback (see research for full text). Key points:
  - IMPLICIT: call save_app_feedback silently when user expresses opinions about bot features/UX. NEVER acknowledge to user.
  - PROACTIVE: when `<request_feedback/>` tag is present, find a natural moment to ask how the experience is going. Casual warm tone. If user responds with feedback, call save_app_feedback with source "proactive". If user ignores, drop it. Only ask ONCE.
- Update the `buildSystemPrompt` function signature to accept an optional `appFeedbackContext?: string` parameter (add after `onboardingContext`)
- Append `APP_FEEDBACK_PROMPT` to the return string (same position pattern as other prompt blocks)
- Append `${appFeedbackContext ? "\n" + appFeedbackContext : ""}` for the `<request_feedback/>` tag injection

**src/pipeline/processor.ts:**
- Import `createAppFeedbackRepository` from `../app-feedback/repository.js`
- Import `APP_FEEDBACK_TOOLS` from `../ai/tools.js`
- Add `appFeedbackRepository` as an optional dependency in the `ProcessorDeps` interface (same type pattern as other repositories)
- Inside `processBatch`, after the onboarding context build (step h2), add proactive prompt logic:
  - Define constant `PROACTIVE_FEEDBACK_THRESHOLD = 50` (50 inbound messages approximates ~2 weeks of moderate use)
  - If `deps.appFeedbackRepository` exists, call `deps.appFeedbackRepository.getMessageCountSinceLastPrompt(householdId)`
  - If count >= threshold, set `appFeedbackContext = "<request_feedback/>"` and immediately call `deps.appFeedbackRepository.recordProactivePromptShown(householdId)` to reset the counter
  - Otherwise `appFeedbackContext = ""`
- Pass `appFeedbackContext` to `buildSystemPrompt()` call (add as last parameter)
- Pass `appFeedbackRepository: deps.appFeedbackRepository` to `createToolHandler()` deps
- Add `...APP_FEEDBACK_TOOLS` to the `allTools` array (after `...FEEDBACK_TOOLS`)

**src/bot/index.ts:**
- Add `appFeedbackHandler` to the `CreateBotOptions` interface (type: `Composer<BotContext>`)
- Add `bot.use(appFeedbackHandler)` BEFORE `remindersHandler` (position: between groceryHandler and remindersHandler, so /feedback is registered before the feedbackTextHandler catch-all)
- Update the middleware order comment at the top of the file

**src/main.ts:**

- Import `createAppFeedbackHandler` from `./bot/handlers/app-feedback.js`
- After feedbackRepository initialization, add: `const appFeedbackRepository = createAppFeedbackRepository(sqlite);`
- After feedbackTextHandler creation, add: `const appFeedbackHandler = createAppFeedbackHandler(sqlite);`
- Pass `appFeedbackRepository` to `createProcessor` deps
- Pass `appFeedbackHandler` to `createBot` options
