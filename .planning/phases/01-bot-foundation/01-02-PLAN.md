       - Import AutoChatActionFlavor from "@grammyjs/auto-chat-action"
       - Export type: `export type BotContext = ParseModeFlavor<AutoChatActionFlavor<Context>>`

    3. Create src/bot/handlers/start.ts:
       - Import Composer from "grammy"
       - Import BotContext type
       - Create and export a Composer<BotContext> named `startHandler`
       - Register a `/start` command that replies with a welcome message:
         "Hey! I'm Sous, your meal planning assistant. I'm still getting set up, but go ahead and say hi!"
       - Use `ctx.reply()` (HTML parse mode is set globally by plugin)

    4. Create src/bot/handlers/message.ts:
       - Import Composer from "grammy"
       - Import BotContext type
       - Create and export a Composer<BotContext> named `messageHandler`
       - Register a handler for `message:text` events
       - For Phase 1, echo the user's message back: `ctx.reply(escapeHtml(ctx.message.text))`
       - Import escapeHtml from the telegram/formatter module (will be created in Plan 03)
       - TEMPORARY: For now, since formatter doesn't exist yet, create a simple inline escape function:
         ```typescript
         function escapeHtml(text: string): string {
           return text.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;");
         }
         ```
         Mark it with a TODO comment: `// TODO: Replace with shared formatter from src/telegram/formatter.ts (Plan 03)`

    5. Create src/bot/middlewares/error-handler.ts:
       - Import GrammyError, HttpError, BotError from "grammy"
       - Import BotContext type
       - Import logger
       - Export function `setupErrorHandler(bot: Bot<BotContext>)`:
         - Use `bot.catch()` to handle all errors
         - Log errors with structured fields: updateId, error type, description
         - For GrammyError: log Telegram API error details
         - For HttpError: log network connectivity issue
         - For unknown errors: log as unhandled
         - Do NOT rethrow -- the error handler is the boundary

    6. Create src/bot/index.ts:
       - Import Bot from "grammy"
       - Import { hydrateReply, parseMode } from "@grammyjs/parse-mode"
       - Import { autoChatAction } from "@grammyjs/auto-chat-action"
       - Import BotContext type
       - Import startHandler, messageHandler
       - Import setupErrorHandler
       - Export function `createBot(token: string): Bot<BotContext>`:
         - Create `new Bot<BotContext>(token)`
         - Set default parse mode: `bot.api.config.use(parseMode("HTML"))`
         - Register middleware in order:
           1. `bot.use(hydrateReply)` -- hydrate reply methods
           2. `bot.use(autoChatAction())` -- auto typing indicator
           3. `bot.use(startHandler)` -- /start command
           4. `bot.use(messageHandler)` -- general messages (MUST be after commands)
         - Call `setupErrorHandler(bot)`
         - Return bot

  <files>

  <action>
    1. Create src/server.ts:
       - Import express and webhookCallback from "grammy"
       - Import Bot from "grammy"
       - Import BotContext type
       - Import logger
       - Export function `createServer(bot: Bot<BotContext>, port: number)`:
         - Create Express app
         - Add `express.json()` middleware
         - Add health check endpoint: `GET /health` returns "ok"
         - Mount webhook handler: `app.use("/webhook/" + bot.token, webhookCallback(bot, "express"))`
           Note: Using bot.token in the URL path acts as a secret to prevent unauthorized webhook calls
         - Return the app (do NOT call listen inside -- let main.ts control that)

    2. Update src/main.ts (replace the placeholder from Plan 01):
       - Import config from ./config.ts
       - Import { createBot } from ./bot/index.ts
       - Import { createServer } from ./server.ts
       - Import { createDatabase } from ./db/index.ts
       - Import { logger } from ./logger.ts
       - Create main async function:
         a. Initialize database: `const db = createDatabase(config.dbFileName)`
         b. Create bot: `const bot = createBot(config.botToken)`
         c. If config.botMode === "webhook":
            - Create server: `const app = createServer(bot, config.port)`
            - Start listening: `app.listen(config.port, () => logger.info({ port: config.port }, "Webhook server listening"))`
            - Set webhook: `await bot.api.setWebhook(config.webhookUrl + "/webhook/" + bot.token)`
            - Log: "Webhook set to {url}"
         d. If config.botMode === "polling":
            - Delete any existing webhook: `await bot.api.deleteWebhook()`
            - Start polling: `await bot.start({ onStart: () => logger.info("Bot started in polling mode") })`
         e. Handle graceful shutdown: listen for SIGINT/SIGTERM, call `bot.stop()`, log "Bot stopped"
       - Call main() and catch any startup errors with logger.error + process.exit(1)
