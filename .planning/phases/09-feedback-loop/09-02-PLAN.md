   `createFeedbackCallbackHandler(deps: { sqlite, feedbackRepository, knowledgeRepository, db })` returns Composer&lt;BotContext&gt;

   Handler logic on "callback_query:data":
   - Parse callback data with parseFeedbackCallback()
   - If not a feedback callback, call next() (passthrough to other handlers)
   - Immediately answerCallbackQuery() to clear loading spinner
   - Map sentiment abbreviation to full FeedbackSentiment: pos->positive, ok->neutral, neg->negative, skip->skipped
   - Look up the check-in by reminderId from feedbackRepository.getCheckinByReminderId()
   - If not found (expired/deleted), edit message to say "This check-in has expired." and return
   - Record the response: feedbackRepository.recordResponse(checkin.id, sentiment, null)
   - Edit the message to show confirmation:
     - positive: "Glad you loved it! I'll remember that."
     - neutral: "Got it, noted for next time."
     - negative: "Sorry it didn't work out. I'll keep that in mind for future suggestions."
     - skipped: "No worries! I'll note that one was skipped."
   - Remove the inline keyboard (edit with no reply_markup)
   - For positive/neutral/negative (NOT skipped): append a feedback annotation to the recipe's knowledge item content
     - Parse mealsJson from the check-in to get knowledgeItemIds
     - For each meal with a knowledgeItemId:
       - Get the knowledge item via knowledgeRepository.getById(id, chatId)
       - If content has a "Feedback:" section, append to it. If not, add a "Feedback:" section.
       - Annotation format: `- YYYY-MM-DD [sentiment]: (button response, no notes)`
       - Update via knowledgeRepository.update(id, chatId, { content: updatedContent })
       - Log to knowledgeChangelog with action "update", change_description "Feedback annotation added"
   - Silently ignore "message is not modified" GrammyError (same as grocery handler)

2. **Create src/feedback/extractor.ts** -- Claude-based structured feedback extraction from free text:

   `extractFeedback(text: string, claudeClient: ClaudeClient): Promise<{ sentiment: FeedbackSentiment, notes: string }>`

   Uses a focused system prompt (NOT the full Sous persona):
   ```
   You extract structured feedback from a user's free-text response about a meal.
   Return a JSON object with two fields:
   - sentiment: one of "positive", "neutral", "negative", "skipped"
   - notes: a brief summary of actionable feedback (what worked, what to change). If the user just said something simple like "great" or "loved it", notes can be empty string.

   Respond ONLY with the JSON object, no other text.
   ```

   - Send the user's text as the user message
   - Parse the JSON response
   - Fallback: if parsing fails, default to { sentiment: "neutral", notes: text }
   - claudeClient interface: minimal, same as reminders/sender.ts pattern:
     ```typescript
     interface ClaudeClient {
       sendMessage: (messages: string[], systemPrompt?: string) => Promise<{ text: string; usage: { inputTokens: number; outputTokens: number; cacheCreationInputTokens: number; cacheReadInputTokens: number } }>;
     }
     ```
