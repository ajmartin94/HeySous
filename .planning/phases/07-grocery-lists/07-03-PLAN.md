<task type="auto">
  <name>Task 1: Inline keyboard builder with callback data encoding</name>
  <files>src/grocery/buttons.ts</files>
  <action>
Create src/grocery/buttons.ts with these exports:

1. GROCERY_CB_PREFIX = "g:" -- constant for identifying grocery callbacks

2. encodeToggle(itemId: number): string
   - Returns `g:t:${itemId}` -- compact format, well under 64 byte Telegram limit
   - Example: encodeToggle(42) returns "g:t:42"

3. parseGroceryCallback(data: string): { action: string; itemId: number } | null
   - If data doesn't start with GROCERY_CB_PREFIX, return null
   - Split after prefix on ":" -- expect exactly 2 parts (action, itemId)
   - Return { action: parts[0], itemId: parseInt(parts[1], 10) }
   - Return null if parsing fails or itemId is NaN

4. buildGroceryKeyboard(items: GroceryItem[]): InlineKeyboard
   - Import InlineKeyboard from "grammy"
   - Import GroceryItem type from "./repository.js"
   - Filter to unchecked items only (checked items are strikethrough text, no buttons)
   - Group unchecked items by store, then by section within each store
   - For each unchecked item, add a button:
     - Label: truncate to fit -- use quantity + name if both exist, just name otherwise
     - Callback data: encodeToggle(item.id)
   - Layout: 2 buttons per row for mobile readability
   - After each section's items, ensure row ends (call keyboard.row() if odd count)
   - If total unchecked items exceed 80, skip buttons entirely and return empty InlineKeyboard (fall back to conversational check-off to stay under Telegram's 100-button limit)
   - Return the InlineKeyboard instance

IMPORTANT: Import from "grammy" (not @grammyjs/anything -- InlineKeyboard is built into grammy core). Use .js extensions on local imports.
  </action>
  <verify>
Run `npx tsc --noEmit` to verify TypeScript compiles. Verify InlineKeyboard import resolves from grammy.
  </verify>
  <done>
Button builder creates InlineKeyboard with per-item toggle buttons for unchecked items. Callback data encoding is compact (under 64 bytes). Builder gracefully handles large lists by skipping buttons over 80 unchecked items.
  </done>
</task>

<task type="auto">
  <name>Task 2: Grocery list HTML formatter with strikethrough</name>
  <files>src/grocery/formatter.ts</files>
  <action>
Create src/grocery/formatter.ts with:

1. Import escapeHtml from "../telegram/formatter.js"
2. Import GroceryItem type from "./repository.js"

3. formatGroceryList(items: GroceryItem[]): string
   - Build an HTML-formatted grocery list as a single string for Telegram
   - Structure:
     - Title: `<b>Grocery List</b>` followed by blank line
     - Group items by store first, then by section within each store
     - Store header: `<b>{storeName}</b>` (escaped)
     - Section header: `<i>{sectionName}</i>` (escaped)
     - Unchecked item: `  - {quantity} {name}` (escaped, quantity omitted if null/empty)
     - Checked item: `  <s>{quantity} {name}</s>` (escaped, strikethrough)
     - Blank line between stores
   - Sort stores alphabetically, sections alphabetically within stores
   - Sort items within sections: unchecked first, then checked (so active items are visible at top)

   Example output:
   ```
   <b>Grocery List</b>

   <b>Costco</b>
   <i>Meat</i>
     - 3 lbs chicken breast
     - 2 lbs ground beef
     <s>1 lb bacon</s>

   <b>Kroger</b>
   <i>Dairy</i>
     - 1 gallon milk
     - 2 cups shredded cheese
   <i>Produce</i>
     - 3 onions
     <s>2 lbs potatoes</s>
   ```

   Per user decision: item format is quantity + item only, NO recipe source attribution. Extra items (snacks, drinks) mixed into appropriate sections, NOT a separate section.

4. formatGroceryListSummary(items: GroceryItem[]): string
   - One-line summary: "{checked}/{total} items checked off"
   - Used in conversational responses after check-off

IMPORTANT: Use .js extensions on all local imports. Use `<s>` tag for strikethrough (confirmed supported in Telegram HTML mode and in codebase's ALLOWED_TAGS).
  </action>
